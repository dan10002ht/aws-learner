# Solution — Practice 01

> ⚠️ Tự làm trước khi đọc.

## Exercise 1 — Setup account
1. Login root (lần cuối) → góc trên phải → **Security credentials**.
2. **Multi-factor authentication** → Assign → Authenticator app → quét QR bằng Google Authenticator / Authy → nhập 2 mã liên tiếp.
3. **IAM** → Users → Create user `learner`:
   - Provide console access → autogenerated → require new password.
   - Attach policy directly → `AdministratorAccess`.
   - Sau khi tạo, vào user → Security credentials → Assign MFA → giống bước trên.
4. **Billing** → **Budgets** → Create budget → Use a template → "Zero spend budget" hoặc custom $1 → email alert.
5. **Sign-out root**, login lại bằng URL `https://<account-id>.signin.aws.amazon.com/console` với user `learner`.

## Exercise 2 — Region & AZ
1. `ap-southeast-1` có **3 AZ**: `ap-southeast-1a`, `1b`, `1c`.
2. `us-east-1` có **6 AZ** — vì đây là region lâu đời và dùng nhiều nhất, AWS mở rộng nhiều lần.
3. Gần Hà Nội nhất: **`ap-southeast-1`** (Singapore, ~50ms) hoặc **`ap-east-1`** (Hong Kong, ~40ms). Region `ap-southeast-3` (Jakarta) cũng gần.
4. **ZoneName** (`ap-southeast-1a`) khác nhau giữa account vì AWS random-map để cân tải. **ZoneId** (`apse1-az1`) là **stable across accounts** — dùng khi cần đảm bảo 2 account share cùng AZ vật lý (ví dụ peering low-latency).

## Exercise 4 — Pricing tham khảo (tháng 5/2026, có thể đổi)
- EC2 `t3.micro` 24/7: ~$8.50 (Singapore đắt hơn us-east-1 ~10%).
- RDS `db.t3.micro` MySQL Multi-AZ: ~$30 (Multi-AZ = 2x giá single-AZ).
- 100GB EBS gp3: ~$8.
- 50GB S3 Standard: ~$1.15.
- 10GB egress: ~$1.20.
**Total ~$48/tháng.**

**Free Tier năm đầu** (mỗi tháng):
- EC2 `t2.micro` hoặc `t3.micro` 750h.
- RDS `db.t2/t3.micro` **single-AZ** 750h (Multi-AZ KHÔNG free).
- 30GB EBS gp2/gp3.
- 5GB S3.
- 100GB egress.

→ Cấu hình trên nếu thay Multi-AZ → single-AZ và giảm EBS xuống 30GB, S3 xuống 5GB thì gần như miễn phí năm đầu, chỉ trả phần dư.
