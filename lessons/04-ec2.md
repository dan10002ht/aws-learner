# Bài 4 — EC2 (Elastic Compute Cloud)

## 1. Mục tiêu
Sau bài này bạn có thể:
- Chọn đúng **instance family + size** cho từng workload.
- Phân biệt 4+ **pricing model** (On-Demand, Reserved, Savings Plans, Spot, Dedicated).
- Phân biệt **EBS vs Instance Store vs EFS**.
- Hiểu **AMI**, **User Data**, **Metadata Service (IMDSv2)**.
- Biết khi nào dùng EC2 vs Lambda vs Fargate.
- Bảo mật EC2 đúng cách (SG, IAM Role thay access key, IMDSv2).

## 2. Lý thuyết

### 2.1 EC2 là gì
EC2 = **virtual server** (VM) chạy trên hạ tầng AWS. Bạn chọn:
- **CPU/RAM/Network** (instance type)
- **OS image** (AMI: Linux, Windows, custom)
- **Storage** (EBS/Instance Store)
- **Network** (VPC, subnet, Security Group)
- **Pricing model**

Tính theo **giây/giờ** (Linux: per-second, min 60s; Windows/RHEL: per-hour).

### 2.2 Instance families & naming
Format: `<family><generation>.<size>` — ví dụ `m6i.large`, `c7g.xlarge`, `t3.micro`.

| Family | Mục đích | Ví dụ |
|--------|----------|-------|
| **T** | Burstable, baseline + credit | `t3.micro`, `t4g.nano` — dev/test, web nhỏ |
| **M** | General-purpose, balanced | `m6i.large`, `m7g.xlarge` — app server |
| **C** | Compute-optimized (CPU mạnh) | `c7i.large` — batch, encoding, HPC |
| **R** | Memory-optimized (RAM nhiều) | `r6i.xlarge` — DB, cache, in-memory |
| **X/Z** | Extreme memory | `x2idn.16xlarge` — SAP HANA |
| **I/D** | Storage-optimized (Instance Store NVMe) | `i4i.large` — NoSQL, data warehouse |
| **G/P/Inf/Trn** | GPU / ML accelerator | `g5.xlarge`, `p4d.24xlarge` — train/inference |
| **HPC** | HPC workload | `hpc7a.96xlarge` |

**Hậu tố hay gặp:**
- `g` — Graviton (ARM, **rẻ hơn 20–40%**, hiệu năng tốt). VD: `m7g`, `t4g`.
- `i` — Intel.
- `a` — AMD.
- `n` — Network optimized (100 Gbps).
- `d` — có Instance Store NVMe.
- `e` — extra memory hoặc enhanced.

→ **Lưu ý đi làm:** Nếu app build được trên ARM (Go/Java/Python/Node), **chuyển sang Graviton là quick win** giảm 20–40% cost cho cùng performance.

### 2.3 T family burstable — cơ chế "credit"
- T-instance có **baseline CPU** (ví dụ `t3.micro` = 10% / 2 vCPU).
- Khi CPU dưới baseline → tích **CPU credit**.
- Khi CPU vượt baseline → **tiêu credit**.
- Hết credit:
  - **Standard mode**: throttle về baseline (chậm lại).
  - **Unlimited mode** (default từ `t3`): vẫn burst, **trả thêm phí** theo vCPU-hour.
- ⚠️ Bẫy đi làm: T-unlimited có thể **vọt cost** nếu app load liên tục cao → nên dùng M family.

### 2.4 AMI (Amazon Machine Image)
- Template OS + pre-installed software → launch nhanh.
- Có 4 nguồn:
  - **AWS-provided**: Amazon Linux 2023, Ubuntu, Windows Server.
  - **Marketplace**: hình ảnh từ vendor (Bitnami, Palo Alto…), có thể tính phí thêm.
  - **Community**: AMI public.
  - **My AMIs**: bạn tự build (ví dụ qua **Packer** hoặc **EC2 Image Builder**).
- AMI **regional** — copy sang region khác phải `aws ec2 copy-image`.
- AMI có 2 backing storage:
  - **EBS-backed** (phổ biến): root volume là EBS, có thể stop/start.
  - **Instance Store-backed** (hiếm): không stop được, mất data khi terminate.

### 2.5 Storage cho EC2

| | EBS | Instance Store | EFS | FSx |
|--|-----|----------------|-----|-----|
| Loại | Block, network-attached | Block, **physical-attached** | NFS file system | Windows SMB / Lustre / NetApp / OpenZFS |
| Persistence | **Survives stop/terminate** | **Mất khi stop/terminate** | Persistent | Persistent |
| AZ | 1 AZ (gắn EC2 cùng AZ) | Same host | **Multi-AZ** | Multi-AZ tuỳ loại |
| Share multi-EC2 | Không (trừ io1/io2 Multi-Attach same AZ) | Không | **Có** (1000s EC2) | Có |
| IOPS/Throughput | Tuỳ type, max 256k IOPS (io2 BX) | **Cực cao**, NVMe local | Auto scale | Lustre cực cao |
| Cost | $/GB/tháng + IOPS phí | Đi kèm instance type | $/GB sử dụng | Cao |
| Snapshot | Có (vào S3) | Không | AWS Backup | Có |
| Use case | Boot, DB, app | Cache, scratch, temp | Shared content, lift-and-shift NFS | Windows file share, HPC |

**EBS volume types:**
| Type | Use case | IOPS | Note |
|------|----------|------|------|
| **gp3** | Default mới | 3000–16000 base, tách size & IOPS | Rẻ hơn gp2 ~20% |
| **gp2** | Default cũ | IOPS = 3 × size GB | Vẫn dùng nhiều, sẽ migrate gp3 dần |
| **io1 / io2** | DB perf cao | Tới 64k (io2 BX: 256k) | Có Multi-Attach (16 EC2 same AZ) |
| **io2 Block Express** | Extreme | 256k IOPS, 4000 MB/s | Nitro only |
| **st1** | Throughput HDD | Big data, log | Không boot được |
| **sc1** | Cold HDD | Backup, archive | Rẻ nhất block |

### 2.6 Pricing models (cực hay ra đề)

| Model | Discount | Cam kết | Use case |
|-------|----------|---------|----------|
| **On-Demand** | 0% | Không | Dev/test, workload không dự đoán |
| **Reserved Instance (RI)** | Tới 72% | 1 hoặc 3 năm, instance family + region | Steady state workload |
| **Savings Plans (Compute)** | Tới 66% | 1/3 năm, commit $/h, **flexible** EC2 + Fargate + Lambda | Workload thay đổi type/region |
| **Savings Plans (EC2 Instance)** | Tới 72% | 1/3 năm, fix family + region | Như RI nhưng size flexible |
| **Spot Instance** | Tới 90% | Không, có thể bị kill trong 2 phút | Stateless, batch, CI, fault-tolerant |
| **Dedicated Host** | Đắt nhất | 1/3 năm hoặc on-demand | License BYOL (Windows, Oracle) — visibility tới socket/core |
| **Dedicated Instance** | Đắt | Per hour | Không share HW với account khác |
| **Capacity Reservation** | Không discount | Per hour | Đảm bảo capacity khi bạn cần |

**Khi nào dùng gì:**
- Prod web 24/7 ổn định → **Savings Plan 1 năm no-upfront**.
- Batch job stateless, có thể retry → **Spot Fleet capacity-optimized**.
- Workload spike khó dự đoán → **On-Demand + Auto Scaling**.
- Cần đảm bảo capacity trong DR region → **Capacity Reservation**.
- License Windows/Oracle tính theo socket → **Dedicated Host**.

### 2.7 Lifecycle states
- **Pending** → instance đang khởi tạo.
- **Running** → có phí compute + EBS.
- **Stopping/Stopped** → **không tính phí compute**, vẫn tính phí EBS, mất Instance Store data, **có thể** đổi instance type.
- **Hibernate** → lưu RAM xuống EBS root, start lại nhanh. Yêu cầu encrypted EBS, certain types.
- **Terminating/Terminated** → xóa instance. EBS root volume xóa theo (default), trừ khi unset `DeleteOnTermination`.
- **Reboot** ≠ Stop/Start — reboot giữ public IP, không thay đổi host.

### 2.8 User Data & Metadata

**User Data**: script chạy **lần đầu boot** (root, /var/log/cloud-init-output.log). Ví dụ:
```bash
#!/bin/bash
yum update -y
yum install -y nginx
systemctl enable --now nginx
echo "<h1>Hello from $(hostname)</h1>" > /usr/share/nginx/html/index.html
```

**Instance Metadata Service (IMDS)**: HTTP endpoint **`http://169.254.169.254/latest/meta-data/`** chỉ accessible từ chính EC2.

⚠️ **IMDSv2 vs v1**:
- **IMDSv1** (legacy): query trực tiếp → bị **SSRF** lợi dụng (Capital One 2019 leak 100M user).
- **IMDSv2**: bắt buộc **session token** (PUT request lấy token trước, GET kèm header).
- **Best practice 2024+**: bắt buộc IMDSv2-only ở launch template, **`HttpTokens=required`**.

Code thường dùng:
```bash
# Lấy token (TTL 6h)
TOKEN=$(curl -s -X PUT "http://169.254.169.254/latest/api/token" \
  -H "X-aws-ec2-metadata-token-ttl-seconds: 21600")

# Dùng token query metadata
curl -s -H "X-aws-ec2-metadata-token: $TOKEN" \
  http://169.254.169.254/latest/meta-data/iam/security-credentials/
```

### 2.9 Security Group (SG) recap
- **Stateful**, instance-level (gắn vào ENI).
- Chỉ rule **Allow**, không có Deny.
- Inbound default: **deny all**. Outbound default: **allow all**.
- Source/destination: CIDR, **SG khác** (self-reference được), prefix list.
- Có thể gắn **nhiều SG** vào 1 ENI — rules **union**.

Best practice:
- SG `web-sg` allow `0.0.0.0/0:443`.
- SG `app-sg` allow `web-sg:8080` (chain by reference, không bằng CIDR cứng).
- SG `db-sg` allow `app-sg:5432`.

### 2.10 Khi nào dùng EC2 vs các option khác

| Workload | Service đúng |
|----------|--------------|
| Code Node/Python ngắn (<15 phút), event-driven | **Lambda** |
| Container không muốn quản EC2, scale to zero | **App Runner** hoặc **ECS Fargate** |
| Container orchestration, customize sâu | **ECS on EC2** / **EKS** |
| Web app traditional, full OS control, GPU, legacy | **EC2** |
| HPC cluster, MPI, low-latency | **EC2 với Placement Group cluster + EFA** |
| Database self-managed | EC2 — nhưng cân nhắc RDS/Aurora trước |
| Batch job có thể bị interrupt | **EC2 Spot** hoặc **AWS Batch** |

### 2.11 Auto Scaling Group (giới thiệu, đi sâu ở SAA)
- **Launch Template** (mới) thay **Launch Configuration** (cũ).
- Min / Desired / Max capacity.
- Health check: EC2 hoặc ELB.
- Scaling policies: Target Tracking, Step, Scheduled, Predictive.
- Multi-AZ → 1 instance/AZ tự balance.

### 2.12 Placement Groups
- **Cluster** — same AZ, low latency, HPC. Risk: AZ down = mất tất.
- **Spread** — 7 instance/AZ, different HW. Đảm bảo isolation.
- **Partition** — up to 7 partition/AZ, HDFS/Kafka.

### 2.13 Elastic IP (EIP)
- **Static public IPv4** thuộc về account, attach vào ENI.
- **Phí khi KHÔNG dùng** (~$3.6/tháng/EIP idle, từ 2024 cả khi đang dùng cũng tính phí $0.005/h).
- Tránh dùng nếu có thể → ưu tiên ALB/NLB hoặc Route 53 alias.

## 3. Hands-on có account

### Lab 1 — Launch EC2 đầu tiên (15 phút, FREE TIER)
```bash
# 1. Tạo key pair
aws ec2 create-key-pair --key-name learn-key \
  --query 'KeyMaterial' --output text > ~/.ssh/learn-key.pem
chmod 400 ~/.ssh/learn-key.pem

# 2. Lấy AMI ID Amazon Linux 2023 mới nhất
AMI=$(aws ec2 describe-images --owners amazon \
  --filters "Name=name,Values=al2023-ami-*-x86_64" "Name=state,Values=available" \
  --query 'sort_by(Images, &CreationDate)[-1].ImageId' --output text)

# 3. Tạo SG cho phép SSH từ IP của bạn
MY_IP=$(curl -s ifconfig.me)
SG=$(aws ec2 create-security-group --group-name learn-ssh \
  --description "Learn SSH" --query 'GroupId' --output text)
aws ec2 authorize-security-group-ingress --group-id $SG \
  --protocol tcp --port 22 --cidr ${MY_IP}/32

# 4. Launch t3.micro với IMDSv2 required
aws ec2 run-instances --image-id $AMI --instance-type t3.micro \
  --key-name learn-key --security-group-ids $SG \
  --metadata-options "HttpTokens=required,HttpPutResponseHopLimit=2" \
  --tag-specifications 'ResourceType=instance,Tags=[{Key=Name,Value=learn-ec2-1},{Key=Project,Value=aws-learner}]'

# 5. SSH vào
aws ec2 describe-instances --filters "Name=tag:Name,Values=learn-ec2-1" \
  --query 'Reservations[].Instances[].PublicIpAddress' --output text
ssh -i ~/.ssh/learn-key.pem ec2-user@<PUBLIC_IP>
```

Trên EC2:
```bash
# Lấy metadata (IMDSv2)
TOKEN=$(curl -s -X PUT "http://169.254.169.254/latest/api/token" \
  -H "X-aws-ec2-metadata-token-ttl-seconds: 21600")
curl -H "X-aws-ec2-metadata-token: $TOKEN" \
  http://169.254.169.254/latest/meta-data/instance-id
```

**Teardown:**
```bash
INSTANCE=$(aws ec2 describe-instances --filters "Name=tag:Name,Values=learn-ec2-1" \
  --query 'Reservations[].Instances[].InstanceId' --output text)
aws ec2 terminate-instances --instance-ids $INSTANCE
aws ec2 delete-security-group --group-id $SG  # chờ instance terminate xong
aws ec2 delete-key-pair --key-name learn-key
```

## 5. Tự kiểm tra

1. App của bạn chạy ổn định 24/7, không đổi region/family trong 3 năm. Pricing nào tối ưu?
   <details><summary>Đáp án</summary>**EC2 Instance Savings Plan 3-year all-upfront** (~72% off). RI cũng OK nhưng SP linh hoạt size hơn.</details>

2. Bạn cần shared file system cho 50 EC2 Linux ở 3 AZ. Chọn gì?
   <details><summary>Đáp án</summary>**EFS** — multi-AZ NFS. EBS không share multi-AZ (Multi-Attach chỉ same AZ và max 16 instance).</details>

3. Spot instance bị reclaim, bạn có bao nhiêu thời gian xử lý?
   <details><summary>Đáp án</summary>**2 phút** notification qua IMDS `/latest/meta-data/spot/instance-action`. Code phải graceful shutdown trong 2 phút.</details>

4. EC2 stop/start có giữ data trên Instance Store không?
   <details><summary>Đáp án</summary>**KHÔNG** — Instance Store mất khi stop hoặc terminate (chỉ giữ khi reboot). EBS thì giữ.</details>

5. Web app cần protect khỏi SSRF. EC2 cấu hình thế nào?
   <details><summary>Đáp án</summary>Bật **IMDSv2 required** (`HttpTokens=required`), set **HopLimit=1** để container/proxy không relay được. Capital One breach 2019 là vì IMDSv1 cho phép SSRF.</details>

6. Bạn cần 100 EC2 chạy song song HPC, latency < 1ms giữa các node. Đặt vào Placement Group nào?
   <details><summary>Đáp án</summary>**Cluster** placement group (same AZ, same rack). Bonus: dùng **EFA (Elastic Fabric Adapter)** cho MPI workload.</details>

7. Reboot khác Stop/Start ở chỗ nào?
   <details><summary>Đáp án</summary>Reboot **giữ host vật lý + public IP + Instance Store data**. Stop/Start **đổi host + đổi public IP (trừ EIP) + mất Instance Store**, có thể đổi instance type.</details>

8. Khi terminate EC2, EBS root volume mặc định bị xóa hay giữ?
   <details><summary>Đáp án</summary>**Xóa** (DeleteOnTermination=true mặc định cho root). Volume gắn thêm thì mặc định **giữ** (false).</details>

## 6. Đối chiếu GCP

| Khái niệm | AWS | GCP |
|-----------|-----|-----|
| VM service | **EC2** | **Compute Engine (GCE)** |
| Instance type | `m6i.large`, `c7g.xlarge` | `n2-standard-4`, `c3-highcpu-4` |
| ARM CPU rẻ | **Graviton** (`g` suffix) | **Tau T2A** / **Axion** |
| Image | **AMI** (regional) | **Image** (multi-regional) |
| Boot disk | **EBS gp3** (network block) | **Persistent Disk** (zonal/regional) |
| Local SSD | **Instance Store NVMe** | **Local SSD** |
| Shared NFS | **EFS** | **Filestore** |
| Auto Scaling | **ASG + Launch Template** | **MIG (Managed Instance Group) + Instance Template** |
| Cheap pre-emptible | **Spot Instance** (2 min warning) | **Spot VM** (30s warning) |
| Discount cam kết | **RI / Savings Plans** | **Committed Use Discount (CUD)** |
| Sustained discount tự động | Không có | **Sustained Use Discount** (auto khi chạy > 25% tháng) |
| Static IP | **Elastic IP** | **Static External IP** |
| Metadata | **IMDS** (`169.254.169.254`, có v1/v2) | **Metadata Server** (`metadata.google.internal`, bắt buộc header `Metadata-Flavor: Google`) |
| Firewall | **Security Group** (per-ENI, stateful, allow-only) | **VPC Firewall Rule** (per-network, stateful, có Allow/Deny + priority) |
| Service identity | **IAM Role + Instance Profile** | **Service Account** attach vào instance |

**5 bẫy lớn khi từ GCE qua EC2:**
1. **Persistent Disk regional** không có equivalent ở EBS. Muốn HA storage → **EFS** hoặc **replication app-level**.
2. **GCE auto sustained discount** (free, automatic). AWS phải **chủ động mua** Savings Plan/RI — quên là mất tiền.
3. **GCP metadata server** dùng header `Metadata-Flavor: Google` (không có v2 token). AWS **bắt buộc IMDSv2 token** mới.
4. **GCP Service Account ≈ AWS IAM Role + Instance Profile**, nhưng GCP gắn 1 service account/VM trực tiếp; AWS phải qua Instance Profile (1 wrapper).
5. **Firewall** GCP có **priority + Deny rules**, AWS SG **chỉ Allow, không priority** (Deny ở NACL level). Đổi mindset khi thiết kế.

**Khi đi làm multi-cloud:**
- Pricing comparator: https://instances.vantage.sh/ cho AWS, https://gcloud-compute.com/ cho GCE.
- Image baking: **Packer** chạy được cả 2 (HCL template chung).
- IaC: **Terraform** > native (CloudFormation/Deployment Manager).

## 7. Lưu ý khi thi CLF-C02
- Nhớ 4 pricing model + use case: On-Demand, Reserved, Spot, Savings Plans.
- EC2 = IaaS (full control OS).
- **Free Tier**: 750h/tháng `t2.micro` hoặc `t3.micro` Linux/Windows, 12 tháng.
- EBS persistent, Instance Store ephemeral.
- Security Group stateful, NACL stateless.
- Khi thấy "fault-tolerant, batch, cost-saving" → **Spot**.
- Khi thấy "license BYOL Windows/Oracle" → **Dedicated Host**.

## 8. Lưu ý khi thi SAA-C03
- **EBS Multi-Attach** chỉ io1/io2 **same AZ**, max 16 instance, application phải cluster-aware (GFS2/OCFS2).
- **Hibernate** yêu cầu encrypted root, RAM ≤ 150GB, only certain instance families, on-demand/reserved (không spot).
- **Placement Group Cluster** rủi ro 1 AZ down → mất hết. Critical → **Spread**.
- **Capacity Reservation** ≠ Reserved Instance. Capacity Res chỉ đảm bảo HW có sẵn (vẫn trả on-demand), không discount. RI/SP là discount.
- **EC2 Image Builder** pipeline tự động build AMI patched hàng tuần — câu hỏi về CI/CD AMI.
- **ASG Lifecycle Hook** + **Warm Pool** giảm scale-out latency.
- **Termination Policy** trong ASG: OldestInstance / NewestInstance / OldestLaunchTemplate / ClosestToNextInstanceHour / Default.
- **Spot Fleet capacity-optimized** strategy ít bị interrupt nhất (khác price-capacity-optimized hoặc lowest-price).
- **EFA (Elastic Fabric Adapter)** cho HPC/MPI, KHÔNG dùng cho TCP/IP thông thường.
- **Nitro System** instances → support EBS encryption by default, IMDSv2, bare metal, hibernation, performance cao hơn.

## 9. Lưu ý khi đi làm

### Cost
- **Đo trước, tối ưu sau**: chạy 2 tuần on-demand → xem CloudWatch CPU/RAM utilization → right-size → mua Savings Plan.
- **Compute Optimizer** (free): gợi ý down-size instance dựa trên 14 ngày metric.
- **Spot Fleet** mix instance types để giảm interruption rate (`capacity-optimized`).
- **Graviton (ARM)** → 20–40% savings cho workload portable.
- **Schedule stop/start** cho dev/test (Instance Scheduler hoặc Lambda + EventBridge) → save 60% (chỉ chạy 9–6 weekday).
- Tag `Environment`, `Owner`, `CostCenter` ngay từ ngày 1 — cost allocation về sau dễ hơn nhiều.

### Bảo mật
- **IMDSv2 required** ở mọi launch template (account-level enforce qua SCP).
- **SSM Session Manager** thay SSH port 22 → no bastion, no inbound rule, full audit trail.
- **Patch Manager (SSM)** auto-patch hàng tuần.
- **EBS encryption by default** bật ở account level mỗi region.
- **AMI Vending** — security team build AMI hardened, dev chỉ dùng AMI approved.
- **Inspector** scan vulnerability EC2 + ECR.
- Không cho EC2 có **public IP** trừ khi cần. Dùng NAT GW cho egress private.

### Anti-pattern thường gặp
- ❌ Access key hardcode trong user-data hoặc app config → dùng **IAM Role**.
- ❌ SSH 0.0.0.0/0 port 22 → **SSM Session Manager**.
- ❌ Self-managed MySQL trên EC2 → cân nhắc **RDS** trước.
- ❌ Snapshot không cross-region → DR thất bại nếu region down. **AWS Backup** với CRR.
- ❌ AMI 2 năm chưa update → vulnerable. Image Builder pipeline.
- ❌ T-unlimited cho prod load cao liên tục → vọt cost, dùng M family.
- ❌ Elastic IP idle → $3.6/tháng/EIP. Release khi không dùng.

## 10. Flashcard

- **EC2** — virtual server, billed per-second (Linux) / per-hour (Windows).
- **AMI** — template OS, regional.
- **Instance type** — `family.size` (m6i.large), Graviton (g) rẻ 20–40%.
- **T burstable** — credit-based, Unlimited mode có thể vọt cost.
- **EBS** — block storage, network-attached, 1 AZ, survives stop/terminate.
- **gp3** — default mới, tách size & IOPS, rẻ hơn gp2 20%.
- **Instance Store** — local NVMe, ephemeral.
- **EFS** — multi-AZ NFS shared.
- **Pricing** — On-Demand / Reserved / Savings Plan / Spot / Dedicated.
- **Spot** — 90% off, 2 min interruption notice.
- **Compute SP** — flexible EC2+Fargate+Lambda. **EC2 SP** — fix family/region, max discount.
- **Capacity Reservation** — reserve HW, không discount.
- **User Data** — script chạy lần đầu boot.
- **IMDS** — `169.254.169.254`, **dùng IMDSv2 (token-based)** chống SSRF.
- **Instance Profile** — container chứa IAM Role gắn vào EC2.
- **Placement Group** — Cluster (HPC) / Spread (isolation) / Partition (HDFS/Kafka).
- **Hibernate** — lưu RAM xuống EBS, encrypted only.
- **EIP** — static public IP, có phí, idle hoặc dùng đều tính (2024+).
- **Nitro** — modern hypervisor, hỗ trợ bare metal, encryption default, IMDSv2, hibernation.
- **Stop/Start** — đổi public IP (trừ EIP), mất Instance Store, có thể change type.
- **Terminate** — xóa instance, root EBS xóa theo default.
