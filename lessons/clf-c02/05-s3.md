# Bài 9 — S3 (Simple Storage Service)

## 1. Mục tiêu
Sau bài này bạn có thể:
- Hiểu S3 model: bucket, object, key, prefix, versioning.
- Phân biệt **7 storage class** và chọn đúng.
- Cấu hình lifecycle, versioning, replication, encryption.
- Bảo mật S3 (Block Public Access, bucket policy, presigned URL, OAC).
- Biết các pattern hay dùng: static website, data lake, backup.

## 2. Lý thuyết

### 2.0 Analogy — S3 như kho hàng có tag

| Khái niệm S3 | Trong kho hàng | Ý nghĩa |
|---------------|------------------|---------|
| **Bucket** | Cả nhà kho (có tên globally unique) | Container chứa object. |
| **Object** | 1 thùng hàng có tag mã vạch | Key + value + metadata. Max 5TB/object. |
| **Object Key** | Mã vạch đầy đủ trên thùng | `folder/sub/file.jpg` — thực ra là **flat key**, không phải folder thật. |
| **Prefix** | Khu vực trong kho | `images/` là prefix của `images/logo.png`. |
| **Storage Class** | Loại kho lưu trữ | Standard (kho tầng 1) → Glacier Deep Archive (kho ngầm xa, lấy mất nửa ngày). |
| **Versioning** | Camera quay lại mọi lần đụng thùng | Lưu version cũ, "xoá" chỉ tạo delete marker. |
| **Lifecycle Rule** | Tự động chuyển kho theo tuổi hàng | 30 ngày → IA, 90 ngày → Glacier, 7 năm → xoá. |
| **Bucket Policy** | Nội quy ai được vào kho làm gì | JSON, gắn vào bucket. |
| **Block Public Access** | Cửa rào ngoài kho | Khoá cấp account/bucket, override mọi policy bên trong. |
| **Pre-signed URL** | Giấy phép vào kho 1 lần có hạn | Cho user không có AWS account download/upload tạm. |
| **CloudFront + OAC** | Quầy lễ tân trước kho | Cache, không cho user vào thẳng kho. |
| **Cross-Region Replication** | Sao y kho ở thành phố khác | DR + low-latency global. |
| **Object Lock (WORM)** | Niêm phong thùng — không xoá được | Compliance (SEC 17a-4, HIPAA). |
| **Encryption (SSE-S3/KMS/C)** | Khoá két trong thùng | At-rest encryption tự động hoặc dùng key của bạn. |

**Quy tắc vàng**: S3 là **object storage flat** — không có folder thật. `folder/file.jpg` chỉ là 1 key chứa dấu `/`. Đừng nhầm với file system.

### 2.0.1 Câu chuyện — 3 vụ S3 leak data lớn nhất thập kỷ

S3 là service bị leak nhiều nhất AWS — không phải vì S3 yếu mà vì **người dùng config sai**.

**Case 1 — Verizon 2017**: 14 triệu khách hàng (số điện thoại, account PIN) leak. Nguyên nhân: bucket S3 đặt ACL **"Authenticated Users"** — đội security tưởng nghĩa là "user của Verizon" nhưng thực ra là **mọi AWS user trên thế giới có account**. Hacker chỉ cần đăng ký AWS free là đọc được.

**Case 2 — Accenture 2017**: 137GB credentials, private keys, dump database public. Nguyên nhân: 4 bucket `acp-*` để **public read** từ thời PoC, quên revert. Researcher Chris Vickery quét scan internet phát hiện.

**Case 3 — Pegasus Airlines 2022**: 23 triệu file flight crew chứa source code + flight data leak. Nguyên nhân: bucket public + không có Block Public Access account-level.

#### 5 cái sai chung
1. **Bucket public access** vẫn cho phép (BPA không bật).
2. **ACL `AllUsers` hoặc `AuthenticatedUsers`** thay vì bucket policy với Principal cụ thể.
3. **Bucket policy `Principal: "*"`** mà không có Condition (IP, MFA, OrgID).
4. **Không có CloudTrail data event** cho S3 → không biết ai đã download.
5. **Không có Macie hoặc S3 Storage Lens** alert khi có hành vi bất thường.

#### Đúng cách (2024+)
1. **Block Public Access account-level = ON** mặc định (AWS bật từ April 2023 cho bucket mới).
2. **Bucket Policy chặt**: `Principal: { "AWS": "arn:aws:iam::123:role/specific-role" }` không bao giờ `"*"`.
3. **CloudFront + Origin Access Control (OAC)** cho static site, **không bao giờ public bucket**.
4. **Encryption SSE-KMS với CMK** cho data nhạy cảm — bonus layer.
5. **Versioning + Object Lock** cho compliance data.
6. **Macie** scan PII tự động, **Access Analyzer** flag bucket share external.
7. **CloudTrail Data Events** + S3 Access Logging.

### 2.0.2 Use case map — chọn storage class nào

| Pattern access | Storage class | Cost (1 GB/tháng) | Min duration | Retrieval |
|----------------|---------------|--------------------|--------------|-----------|
| Truy cập thường xuyên (vài lần/ngày) | **Standard** | $0.023 | 0 | Ngay |
| Truy cập không đoán được (mix nóng/lạnh) | **Intelligent-Tiering** | $0.023 + monitoring | 0 | Ngay |
| Truy cập 1-2 lần/tháng | **Standard-IA** | $0.0125 | 30 ngày | Ngay (retrieval fee) |
| Truy cập 1-2 lần/tháng, **1 AZ** OK | **One Zone-IA** | $0.01 | 30 ngày | Ngay |
| Archive, truy cập ms vài lần/quý | **Glacier Instant Retrieval** | $0.004 | 90 ngày | Ngay |
| Archive truyền thống, OK đợi vài phút - vài giờ | **Glacier Flexible** | $0.0036 | 90 ngày | 1 phút - 12h |
| Long-term archive (compliance 7-10 năm) | **Glacier Deep Archive** | **$0.00099** | 180 ngày | 12-48h |

**Quy tắc kinh tế**:
- IA / Glacier có **retrieval fee** khi download. Truy cập thường → vẫn dùng Standard rẻ hơn tổng.
- **Min duration**: Standard-IA bị xoá trong 30 ngày vẫn tính tiền 30 ngày → đừng dùng cho data ngắn ngày.
- Dùng **Lifecycle Rule** chuyển tự động: 30d Standard → IA → 365d Glacier → 7y Deep Archive → xoá.

### 2.0.3 5 hiểu lầm phổ biến về S3

1. **"S3 có folder"** — SAI. S3 là **flat key namespace**. `folder/file.jpg` chỉ là 1 key chứa ký tự `/`. Console hiển thị "folder" là UI tạo từ prefix. Đừng dùng API `ListObjects` rồi parse "folder" — dùng `Delimiter='/'` để gom prefix.

2. **"Versioning bật = backup an toàn"** — SAI một phần. Versioning lưu version cũ trong **cùng bucket cùng region**. Nếu bucket bị xoá (hoặc IAM role admin bị compromise rồi delete bucket + all versions) → mất hết. Backup thật cần **Cross-Region Replication** + **Object Lock (Compliance mode)** + **MFA Delete** + **separate account backup**.

3. **"Lifecycle rule xoá object cũ = backup safety"** — SAI ngược. Lifecycle **xoá vĩnh viễn**, không phải archive. Object xoá xong **không restore được** (trừ khi có versioning + chưa hết retention). Lifecycle dùng để **giảm cost**, không phải backup.

4. **"S3 transfer chậm hơn EBS"** — SAI tuỳ context. S3 có **throughput nearly unlimited** nếu chia prefix đúng (mỗi prefix support 3,500 PUT/s, 5,500 GET/s; có thể request tăng). Có thể nhanh **hơn EBS** với parallel multipart upload. Tuy nhiên **latency per-object** cao hơn EBS (50-100ms vs 0.5ms).

5. **"S3 Glacier là 1 service riêng"** — SAI từ 2018. Glacier giờ là **storage class trong S3** (S3 Glacier Instant / Flexible / Deep Archive). Vẫn còn legacy "Amazon Glacier" service (vault) nhưng AWS không khuyến nghị nữa — dùng S3 Glacier storage class.

### 2.1 Khái niệm cốt lõi
- **Bucket** — container chứa object. Tên **globally unique** (toàn AWS), DNS-compatible (3–63 ký tự, lowercase, không dấu chấm cuối, không IP format).
- **Object** — file + metadata. Tối đa **5 TB / object** (multipart upload bắt buộc cho > 5GB, khuyến nghị > 100MB).
- **Key** — full path (vd `images/2026/01/avatar.png`). S3 là **flat namespace** — "folder" thực chất là prefix.
- **Region** — bucket nằm 1 region cố định. Object replicate cross-region phải cấu hình CRR.
- **Durability**: **11 nines** (99.999999999%) — mất 1 object trong 10 triệu năm.
- **Availability**: 99.99% (Standard).

### 2.2 Storage Classes (cực hay ra đề)

| Class | Min duration | Retrieval time | Retrieval fee | Use case |
|-------|--------------|----------------|---------------|----------|
| **Standard** | - | ms | Không | Access thường xuyên |
| **Intelligent-Tiering** | - | ms | Không | Pattern không dự đoán; auto move tier |
| **Standard-IA** | 30 ngày | ms | $/GB | Backup, DR, ít access nhưng cần nhanh |
| **One Zone-IA** | 30 ngày | ms | $/GB | Re-creatable data, **1 AZ only** (rẻ hơn IA 20%) |
| **Glacier Instant Retrieval** | 90 ngày | ms | $$/GB | Archive truy cập quarterly |
| **Glacier Flexible Retrieval** | 90 ngày | 1 phút – 12h | $$/GB | Archive truy cập hằng năm |
| **Glacier Deep Archive** | 180 ngày | 12–48h | $$$/GB | Compliance 7–10 năm, **rẻ nhất** |

**Mẹo thi (keyword → class):**
- "Frequently accessed" → **Standard**
- "Unknown pattern, optimize automatically" → **Intelligent-Tiering**
- "Infrequent, but need ms when accessed" → **Standard-IA** hoặc **Glacier Instant**
- "Re-creatable, 1 AZ OK" → **One Zone-IA**
- "Archive, OK chờ vài giờ" → **Glacier Flexible**
- "Compliance 7 năm, rẻ nhất" → **Deep Archive**

⚠️ **Min duration charge**: nếu delete object trước thời gian min, vẫn trả full min charge.

### 2.3 Versioning
- Bật ở bucket level, **không tắt được** (chỉ suspend).
- Mỗi PUT cùng key tạo **version mới**, không ghi đè.
- DELETE đặt **delete marker**, version cũ vẫn còn → restore được.
- **MFA Delete** (chỉ root + CLI) — bắt buộc MFA để xóa version → chống ransomware/accident.
- Phí: trả tiền cho **mọi version**.

### 2.4 Lifecycle Rules
JSON config tự động move/expire object theo tuổi:

```json
{
  "Rules": [{
    "ID": "logs-archival",
    "Filter": { "Prefix": "logs/" },
    "Status": "Enabled",
    "Transitions": [
      { "Days": 30,  "StorageClass": "STANDARD_IA" },
      { "Days": 90,  "StorageClass": "GLACIER" },
      { "Days": 365, "StorageClass": "DEEP_ARCHIVE" }
    ],
    "Expiration": { "Days": 2555 },
    "NoncurrentVersionExpiration": { "NoncurrentDays": 90 }
  }]
}
```

**Lưu ý cost:**
- **Transition** có phí $/1000 request.
- Object < 128KB không nên move IA (min size charge IA = 128KB).

### 2.5 Encryption
- **SSE-S3** (`AES256`) — AWS managed key, free, **default từ Jan 2023** cho mọi bucket mới.
- **SSE-KMS** — Customer/AWS managed key trong KMS, CloudTrail log key usage, **$1/key/tháng + API call**.
- **SSE-C** — Bạn cung cấp key mỗi request, AWS không giữ key.
- **DSSE-KMS** — Dual layer, top secret workload.
- **Client-side** — encrypt trước khi upload (KMS hoặc lib riêng).

**Bucket Key** — giảm KMS API call ~99% bằng cách cache data key ở bucket level. Bật khi dùng SSE-KMS.

### 2.6 Bucket Policy vs ACL vs IAM
3 cách kiểm soát quyền:

1. **IAM Policy** (identity-based) — gắn user/role, áp dụng mọi bucket.
2. **Bucket Policy** (resource-based, JSON) — gắn bucket, có Principal, hỗ trợ cross-account.
3. **ACL** (legacy XML) — gần như deprecated, ít dùng, **mặc định disabled** từ 2023.

→ Best practice: **dùng Bucket Policy + IAM**, **disable ACL** (bật "Bucket owner enforced").

**Block Public Access** (BPA) — 4 settings, **bật ở account level** chặn mọi public access dù policy/ACL cho phép.

### 2.7 Presigned URL
- URL tạm thời cho phép GET/PUT object **không cần AWS credential**.
- Sign bằng credential của caller, hết hạn theo expires (max 7 ngày với SigV4 + IAM user; với role thì < session expiry).

```bash
aws s3 presign s3://my-bucket/file.pdf --expires-in 3600
```

Use case: upload trực tiếp từ browser, download file private có thời hạn.

### 2.8 Replication
- **CRR (Cross-Region Replication)** — replicate sang bucket region khác. Use case: DR, latency.
- **SRR (Same-Region Replication)** — replicate trong cùng region. Use case: log aggregation, account separation.
- Yêu cầu: **versioning bật cả 2 bên**, role có quyền.
- **Replicate KHÔNG retroactive** — chỉ object PUT sau khi bật replicate. Muốn replicate object cũ → **S3 Batch Replication**.
- **Replication Time Control (RTC)** — SLA 15 phút, có phí.

### 2.9 Static Website Hosting
- Bật **Static website hosting** trên bucket, set `index.html` + `error.html`.
- Endpoint: `http://<bucket>.s3-website-<region>.amazonaws.com` (HTTP only!).
- **HTTPS** → phải đặt CloudFront ở trước.
- **Best practice 2024+**: bucket private + CloudFront + **OAC (Origin Access Control)** thay OAI cũ.

### 2.10 Event Notification
S3 events (`s3:ObjectCreated:*`, `s3:ObjectRemoved:*`, …) → trigger:
- **Lambda**
- **SQS**
- **SNS**
- **EventBridge** (mới, schema + filter mạnh hơn)

Use case: image processing pipeline, ETL trigger, audit log.

### 2.11 S3 Object Lock (WORM)
- Bật ở bucket level **khi tạo bucket** (không enable sau).
- **Governance mode** — user có quyền đặc biệt mới override được.
- **Compliance mode** — **không ai** override được, kể cả root.
- **Retention period** + **Legal Hold** (vô thời hạn).
- Use case: compliance SEC 17a-4, FINRA, GDPR.

### 2.12 Performance
- **3500 PUT/s và 5500 GET/s per prefix** — auto scale.
- **Multipart upload** parallel cho object > 100MB.
- **Transfer Acceleration** — upload qua Edge Location (giống CloudFront ngược), thêm phí, dùng cho global user upload region xa.
- **S3 Select / Glacier Select** — SQL trên CSV/JSON/Parquet object, chỉ trả về bytes cần thiết → giảm network.
- **Byte-range fetch** — parallel download chunks.

### 2.13 S3 các feature khác
- **Requester Pays** — caller trả bandwidth thay owner.
- **Access Points** — tạo nhiều endpoint với policy riêng cho 1 bucket (multi-tenant).
- **Multi-Region Access Point** — 1 endpoint global routing tới bucket replicate ở nhiều region.
- **Storage Lens** — analytics dashboard cost + usage toàn organization.
- **Inventory** — báo cáo CSV/Parquet list mọi object hàng ngày/tuần.

### Lab 1 — Bucket + upload cơ bản (5 phút)
```bash
BUCKET="learn-s3-$(aws sts get-caller-identity --query Account --output text)-$(date +%s)"
REGION="ap-southeast-1"

aws s3api create-bucket --bucket $BUCKET --region $REGION \
  --create-bucket-configuration LocationConstraint=$REGION

# Upload

aws s3 cp /tmp/hello.txt s3://$BUCKET/folder/hello.txt

# List
aws s3 ls s3://$BUCKET/folder/

# Download
aws s3 cp s3://$BUCKET/folder/hello.txt /tmp/got.txt
```

### Lab 2 — Versioning + restore (10 phút)
```bash
aws s3api put-bucket-versioning --bucket $BUCKET \
  --versioning-configuration Status=Enabled

# Upload 3 phiên bản
for i in 1 2 3; do echo "v$i" > /tmp/file.txt; aws s3 cp /tmp/file.txt s3://$BUCKET/file.txt; done

# Xem version
aws s3api list-object-versions --bucket $BUCKET --prefix file.txt

# Delete → tạo delete marker
aws s3 rm s3://$BUCKET/file.txt

# Restore: xóa delete marker
DM_VER=$(aws s3api list-object-versions --bucket $BUCKET --prefix file.txt \
  --query 'DeleteMarkers[0].VersionId' --output text)
aws s3api delete-object --bucket $BUCKET --key file.txt --version-id $DM_VER
```

## 5. Tự kiểm tra

1. Bucket name `My_Bucket` có hợp lệ không?
   <details><summary>Đáp án</summary>**Không**. Bucket name phải lowercase, không underscore (chỉ dash). Đúng: `my-bucket`.</details>

2. Object 6GB upload bằng PUT đơn → kết quả?
   <details><summary>Đáp án</summary>**Fail**. PUT max 5GB. Phải dùng **multipart upload** (CLI tự làm khi > 8MB default).</details>

3. Bạn muốn giữ log compliance 7 năm, query 1 lần/năm. Storage class nào rẻ nhất?
   <details><summary>Đáp án</summary>**Glacier Deep Archive** (~$0.00099/GB/tháng). Retrieval 12–48h OK vì hiếm.</details>

4. App upload object 1MB vào IA → trả phí bao nhiêu data?
   <details><summary>Đáp án</summary>**128KB minimum**, dù object 1MB. Object nhỏ KHÔNG nên dùng IA.</details>

5. Sau khi enable versioning, có thể disable hoàn toàn không?
   <details><summary>Đáp án</summary>**Không** — chỉ **suspend**. Suspend = không tạo version mới nữa, version cũ vẫn còn.</details>

6. Public bucket chỉ accessible từ IP văn phòng. Cấu hình thế nào?
   <details><summary>Đáp án</summary>Bucket policy với `Condition: { "IpAddress": { "aws:SourceIp": "203.0.113.0/24" } }`. Hoặc bucket private + Interface VPC Endpoint + Endpoint Policy.</details>

7. Replication có replicate object cũ không?
   <details><summary>Đáp án</summary>**Không**, chỉ object mới sau khi bật. Replicate object cũ → **S3 Batch Replication**.</details>

8. CloudFront serve S3 private content → dùng gì để authorize?
   <details><summary>Đáp án</summary>**OAC (Origin Access Control)** mới — dùng SigV4, hỗ trợ SSE-KMS. OAI cũ deprecated.</details>

## 6. Đối chiếu GCP

| Khái niệm | AWS S3 | GCP Cloud Storage |
|-----------|--------|-------------------|
| Container | **Bucket** (globally unique name) | **Bucket** (globally unique) |
| Class — hot | Standard | Standard |
| Class — warm | Standard-IA | Nearline (30d min) |
| Class — cold | Glacier Instant / Flexible | Coldline (90d min) |
| Class — coldest | Deep Archive | Archive (365d min) |
| Auto-tier | Intelligent-Tiering | Autoclass |
| 1-AZ rẻ | One Zone-IA | **Không có** |
| Region scope | 1 region | **1 region / dual-region / multi-region** (us, eu, asia) |
| Versioning | Có | Có (Object Versioning) |
| Lifecycle | JSON rule | JSON rule (gần giống) |
| Retention/WORM | **Object Lock** (Governance/Compliance) | **Bucket Lock** + **Retention Policy** |
| Static website + HTTPS | S3 + CloudFront + OAC | GCS + Load Balancer + Managed Cert |
| Sign URL | **Presigned URL** (SigV4) | **Signed URL** (V4 signing) |
| Notification | Lambda/SQS/SNS/EventBridge | Pub/Sub |
| Cross-region copy | **CRR** | **Turbo Replication** / dual-region built-in |
| ACL | Có (legacy, disable) | Có (uniform vs fine-grained) |
| Replicate sang non-versioned | Không | Không |
| Default encryption | SSE-S3 (2023+) | Google-managed (luôn bật) |

**5 bẫy khi từ GCS qua S3:**
1. **Multi-region bucket** GCS sẵn có; S3 bị khoá 1 region → muốn multi-region phải CRR hoặc **Multi-Region Access Point**.
2. **GCS Autoclass** = AWS Intelligent-Tiering — nhưng GCS Autoclass đơn giản hơn (chỉ Standard ↔ Nearline ↔ Coldline ↔ Archive theo access pattern). S3 IT có 4 tier + 3 archive tier.
3. **S3 ACL bị disable mặc định** từ 2023 (Bucket Owner Enforced). Đừng cố enable lại nếu không thật sự cần.
4. **S3 BPA (Block Public Access)** ở 4 settings tách rời ACL/Policy — bật cả 4 luôn ở account level (GCS không có khái niệm này, dùng **Public Access Prevention** đơn giản hơn).
5. **Min duration charge** chính xác hơn ở S3 (IA 30 ngày, Glacier 90/180 ngày). GCS cũng có nhưng tính khác chút (Nearline 30d, Coldline 90d, Archive 365d).

**Khi đi làm:**
- Sync giữa S3 ↔ GCS: dùng **rclone**, **gsutil rsync s3://**, hoặc **AWS DataSync** + **Storage Transfer Service**.
- Multi-cloud data lake: hold metadata ở 1 nơi (Glue Data Catalog hoặc Data Catalog GCP), object có thể replicate cả 2.

## 7. Lưu ý khi thi CLF-C02

- Nhớ **7 storage class** + min duration + retrieval time.
- Durability **11 nines**, Availability **99.99%** (Standard).
- Object max **5 TB**, single PUT max **5 GB**, multipart cho > 100MB.
- **Block Public Access** bật mặc định cho bucket mới (2023+).
- Encryption mặc định SSE-S3 (2023+).
- Versioning + MFA Delete chống ransomware.
- Lifecycle để tự động archive.
- **Cross-Region Replication** = DR, **Same-Region Replication** = log aggregation.
- Static website **HTTP only** trực tiếp; HTTPS phải qua CloudFront.

## 8. Lưu ý khi thi SAA-C03

- **S3 Transfer Acceleration** cho upload global xa region → CloudFront ngược.
- **S3 Select** giảm bytes transfer khi query CSV/JSON/Parquet.
- **Multipart upload** > 100MB; **abort incomplete** lifecycle bắt buộc.
- **Replication Time Control (RTC)** SLA 15 phút có phí.
- **Multi-Region Access Point** → 1 endpoint global, routing đến bucket gần nhất.
- **Access Points** với policy riêng cho multi-tenant.
- **Object Lock Compliance** mode **không ai** override (kể cả root). Governance mode user có quyền `BypassGovernanceRetention` thì OK.
- **Glacier Vault Lock** vs **Object Lock**: Vault Lock cho Glacier vault (legacy), Object Lock cho S3 bucket (mới).
- **Requester Pays** + cross-account → caller trả egress.
- **S3 Bucket Key** giảm KMS cost ~99%.
- **Cross-account upload**: object owner mặc định = uploader. Dùng **Bucket Owner Enforced** ACL để bucket owner luôn own object.

## 9. Lưu ý khi đi làm

### Bảo mật
- **Bật Block Public Access ở account level** ngay từ ngày 1.
- **Disable ACL** (Bucket Owner Enforced) cho bucket mới.
- **SSE-KMS với Customer Managed Key** + Bucket Key cho data nhạy cảm.
- **Versioning + MFA Delete** cho bucket prod.
- **Macie** scan PII tự động.
- **Access Analyzer for S3** cảnh báo bucket public/external.
- **CloudTrail Data Events** cho S3 → audit GetObject/PutObject (có phí, bật bucket quan trọng).
- Bucket policy `aws:SecureTransport` deny HTTP:
  ```json
  { "Effect": "Deny", "Principal": "*", "Action": "s3:*",
    "Resource": ["arn:aws:s3:::bucket", "arn:aws:s3:::bucket/*"],
    "Condition": { "Bool": { "aws:SecureTransport": "false" } } }
  ```

### Cost
- **Intelligent-Tiering** cho data unknown pattern → AWS tự move tier.
- **Lifecycle abort incomplete multipart** cho **mọi** bucket → tránh orphan parts.
- **Storage Lens** monthly review.
- Không lưu log CloudWatch dài → export Firehose → S3 + lifecycle Glacier Deep Archive.
- CloudFront trước S3 → giảm GET cost + egress.

### Anti-pattern
- ❌ Bucket name có dấu chấm `.` → break HTTPS SNI.
- ❌ Lưu hàng triệu object < 128KB ở Glacier → tốn min size charge nhiều hơn Standard.
- ❌ Object Lock Compliance mode mà retention 99 năm → **không xóa được**, lock vĩnh viễn data.
- ❌ Lifecycle move object < 30 ngày vào IA → trả full 30 ngày charge dù delete.
- ❌ Static website endpoint HTTP cho người dùng → MITM. Luôn CloudFront + HTTPS.
- ❌ Public bucket "tạm" cho dev → quên tắt, leak.

## 10. Flashcard

- **Bucket** — globally unique, lowercase, 3–63 char, 1 region.
- **Object** — max 5 TB, key = path (flat namespace).
- **Durability** — 11 nines.
- **Storage classes** — Standard / IT / Standard-IA / One Zone-IA / Glacier Instant / Glacier Flexible / Deep Archive.
- **Min duration** — IA 30d, Glacier 90d, Deep Archive 180d.
- **Min size charge** — IA 128KB, Glacier 40KB.
- **Versioning** — bật xong chỉ suspend được, không tắt.
- **Lifecycle** — transition + expiration + abort multipart.
- **Encryption** — SSE-S3 default 2023+, SSE-KMS với Bucket Key, SSE-C, DSSE-KMS.
- **BPA** — Block Public Access, 4 settings, bật account level.
- **Replication** — CRR (cross-region) + SRR (same-region), versioning required.
- **Object Lock** — WORM, Governance/Compliance mode.
- **Presigned URL** — temp access, max 7 ngày SigV4 IAM user.
- **OAC** — Origin Access Control (replace OAI) cho CloudFront → private S3.
- **Multipart** — bắt buộc > 5GB, khuyên > 100MB.
- **Transfer Acceleration** — upload qua Edge.
- **S3 Select** — SQL query trên object.
- **Static website** — HTTP only direct, HTTPS qua CloudFront.
- **Event Notification** — Lambda/SQS/SNS/EventBridge.
